Add artwork and update your portfolio through Pages CMS. Your files stay in GitHub.

Open portfolio editor
  1. Sign in with your GitHub account.
  2. On the first visit, allow the Pages CMS GitHub App to access bekri.github.io.
  3. Open bekri / bekri.github.io and choose the published branch (main after the rework is merged).
  4. Open Portfolio projects, add a project, upload artwork and save. You can drag entries to reorder them.

Changes appear after GitHub Pages finishes publishing. While reviewing the rework, choose the portfolio-3d-rework branch to edit the new content without changing the live site.
